# FdF — каркасная 3D-модель карты высот

![скриншот](docs/screenshot.png)

## Описание

Программа читает карту высот в формате FDF, строит каркасную 3D-модель в изометрической проекции и отображает её в окне. Проект реализован на Python без жёсткой привязки к графической библиотеке в логике, а визуализация вынесена в отдельный модуль интерфейса.

## Установка и запуск

```bash
python -m venv .venv
. .venv/bin/activate  # Linux/macOS
# или .\.venv\Scripts\activate  # Windows
pip install -r requirements.txt
python main.py maps/elem.fdf
```

## Управление

| Клавиша | Действие |
| --- | --- |
| Esc | Завершить приложение |
| = / - | Изменить высоту z_scale |
| v | Переключить изометрию / вид сверху |
| Кнопка закрытия окна | Завершить приложение |

## Формат карты

Файл карты хранит сетку высот: каждая строка описывает координату y, каждый элемент — x, а число — высоту z.

```text
0 0 0 0 0
0 2 2 2 0
0 2 5 2 0
0 2 2 2 0
0 0 0 0 0
```

Допускается цвет в формате `value,color`, например `2,0xFF8800`. Цвет хранится в верхнем регистре как `#RRGGBB`.

## Структура проекта

- `main.py` — точка входа и обработка аргументов командной строки.
- `fdf/parser.py` — чтение и валидация файла карты.
- `fdf/model.py` — структура карты и точек.
- `fdf/projection.py` — изометрическая проекция и цветовые интерполяции.
- `fdf/app.py` — графический интерфейс на pygame.
- `tests/` — модульные тесты.
